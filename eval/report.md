# 평가 리포트 — 모의 추출기 기준

> **이 수치는 LLM 정확도가 아닙니다.** 키 없이 돌리는 기본 모드의 **모의 추출기(규칙·정규식 기반 대체 구현, LLM 아님)**를 가상 문서 30건에 돌린 결과입니다. 모의 추출기는 이 저장소의 가상 양식에 맞춰 만들었으므로 필드 정확도는 높게 나오는 것이 정상이며, 이 리포트에서 볼 것은 **실패가 사람 확인 대기열로 정확히 가는지**(검증·분기 설계)입니다. 실제 LLM 평가는 API 키를 넣고 `python -m pipeline.run --provider gemini`(또는 `anthropic`, `openai`)로 실행하면 같은 형식의 리포트가 생성됩니다.

- 공급자: 모의 추출기(규칙·정규식 기반, LLM 아님)
- 문서: 30건(계약서·견적서·청구서 각 10건, 어려운 케이스 15건) · 모두 생성 스크립트로 만든 가상 문서
- 공급자 오류 시뮬레이션: IV-05, QT-04 문서에 일시 오류 503을 주입 (데모 설정, 재시도 대기 시간은 생략)
